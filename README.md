# Josh Muthumani's Mac apps

A Homebrew tap for my Mac apps. Each app has its own page and its own releases.

```bash
brew tap joshmuthumani/apps
```

| App | What it does | Install |
|---|---|---|
| [**Keyfold**](keyfold/README.md) | Search menu shortcuts, macOS system shortcuts and supported global hotkeys in one window. | `brew install --cask joshmuthumani/apps/keyfold` |

Releases are tagged by app, for example `keyfold-v0.2.0`. To see one app's releases, open its page or [filter the releases list](https://github.com/joshmuthumani/homebrew-apps/releases?q=keyfold-v&expanded=true).

Found a problem? [Open an issue](https://github.com/joshmuthumani/homebrew-apps/issues) and name the app.
